# Changelog

## 1.3.0

- 3D avatar viewer: click an account's picture, Fleet downloads Roblox's own 3D model and shows it turning; drag to rotate, scroll to zoom

## 1.2.0

- Account tools (Tools > Account tools): summary of all accounts, quick selection (all, invert, working, signed out, running, by group), sort and reorder, bulk rename, bulk edit of game, note, FPS cap and proxy, duplicate finder, and export of the selected accounts as cookies, user:pass:cookie or a summary CSV

## 1.1.0

- Four light themes (Paper, Snow, Sand, Sky); the whole interface follows the theme
- Smooth animations: page slides, staggered cards, count-up numbers, toasts, pulsing running dots, drop-down reveal, spinners
- Account details: age, Premium, Robux, friends and followers
- Import accounts from other managers
- Discord Rich Presence
- Whole-PC memory cleaner, manual and automatic
- Experimental proxy settings for the Roblox process

## 1.0.0

First release of Fleet.

- Accounts as cards or a list with groups, tags, colours, notes, aliases, Robux and mute, browser login and cookie paste
- Fast overlapping launches, exact and private servers, follow a player, public server browser, game search
- Saved private servers with link check
- Health page and event log, auto-relaunch watcher, crash breaker
- Performance controls, quick and community configs, shareable configs
- Window tiling, presets, macro recorder, mini window, compact mode, tray, hotkeys
- Eight black themes, custom themes, ten languages, first-run setup
- Proxies, Discord alerts, Roblox version changer, portable mode, backups, password protection, updater
