# Changelog

## 1.0.0

First release of Fleet.

- Accounts as cards or a list with groups, tags, colours, notes, aliases, Robux and mute, browser login and cookie paste
- Fast overlapping launches, exact and private servers, follow a player, public server browser, game search
- Saved private servers with link check
- Health page and event log, auto-relaunch watcher, crash breaker
- Performance controls, quick and community configs, shareable configs
- Window tiling, presets, macro recorder, mini window, compact mode, tray, hotkeys
- Eight black themes, custom themes, ten languages, first-run setup
- Proxies, Discord alerts, Roblox version changer, portable mode, backups, password protection, updater
